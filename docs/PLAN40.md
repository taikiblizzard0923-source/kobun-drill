# 毎日40分で古文7〜8割に届くための逆算プラン（2026-11-15 作成・同日 60分→40分に変更）

> 国数英とのバランスで古文は1日40分に決定（古文は総点の約1割のため）。下の60分案から、★解き直し・音読を外し、知識小問は週3回（月・水・金）、2セットある日の2つ目は任意にした。本番日は30分、11/15（Day 0）は60分のまま。

## ゴール
併願校の古文で7〜8割（明治全学部・上智・明治政経など挑戦校は8割、女子大・東洋・明学は確実に8割超）。
根拠は docs/research と data/guide.js の合格最低点・形式。

## 7〜8割に必要な力と、残り日数で足りるか
| 力 | 必要量 | 今のドリルでの量 | 足りないもの |
|---|---|---|---|
| 古文単語 | 600語前後＋連語 | 11/16〜12/13で420語、以後毎日3語＋復習12語＝計約620語 | 足りる。毎日の復習を確実にやる |
| 文法（助動詞・識別・敬語） | 一通り＋入試の形で正答 | 11/16〜11/23に集中、以後は小問とGで反復 | 足りる |
| 読解（主語・心情・和歌・内容合致） | 本文を毎日1題以上 | 平日1題・土日2題 | ほぼ足りる |
| **現代語訳を自分で書く力** | 東京女子（逐語訳記述3＋心情説明）、日本女子（訳の記述2＋説明1）、明学・明治政経（短い記述） | 11/16〜12/13 はほぼゼロ、以後も大学型の日だけ | **大きく不足** → 毎日「訳トレ」を追加 |
| 文学史・古文常識・和歌修辞 | 明治全学部・学習院・東洋・明治政経・上智で毎回1問前後 | G と各セットに散発 | **不足** → 平日に「知識小問」を追加 |
| 間違い直し（★） | ★を9割以上取る | 解き直しボタンはあるが時間を取っていない | **時間がない** → 毎日10分を固定 |

## 1日40分の型（決定）
単語15語 5分 → その日のメインのセット 20〜25分 → 訳トレ 10分 →（月・水・金）知識小問 6分。2セットある日の2つ目は任意。

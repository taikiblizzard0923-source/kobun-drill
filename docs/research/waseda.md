### 1-3. 設問の型と数

**2025年度（河合塾の分析から。確信度 高）**: 7問・解答数8。全問マーク。
- 文法（助動詞「べし」の意味）1
- 敬意の対象 1問（枝問2つ: 謙譲語と尊敬語の敬意の対象）
- 内容把握 1（重要語の意味を知っていることが前提）
- 内容説明 1
- 語の内容（形容詞の意味）1
- 和歌中の空欄に入る語句の選択 1
- 内容合致（**合致しないもの**を選ぶ）1。河合塾はこれを「やや難」とした。

**2026年度（代ゼミの概評・解答例から。確信度 高）**: 7問・解答数7。全問マーク・5択。
- 空欄補充 2、解釈 2、内容把握 2、内容合致 1。和歌の設問はなかった。

**2024年度（検索要約から。確信度 中）**: 7問。動詞の活用の種類を見分ける設問（下二段の識別）があった。問一・問二の選択肢問題が難しいという評価。和歌の前後の文脈から和歌を選ぶ空欄補充があり、**選択肢がすべて和歌**だった。

### 2-3. 設問の型と数

**2026年度（代ゼミの概評・解答例から。確信度 高）**: 古文は問十一〜問十六の6問で、解答数は10。

## 4. 予想問題の仕様の提案

### 4-1. 法学部型（大問(一)想定・目安20分・全問マーク）

| 項目 | 仕様 |
|---|---|
| 本文 | 900〜1,300字（標準は1,100字前後）。短い年への対策として600字前後の版も作る。 |
| 題材 | 中世〜近世の和歌入りの日記・紀行・擬古物語・随筆・歌論（オリジナルの擬古文、または著作権の切れた作品から自作の設問）。**和歌1〜2首を必ず入れる**。注釈は2〜4個に絞る。 |
| 設問数 | 7問（解答数7〜8） |
| 型の配分 | 文法（助動詞の意味または識別）1／敬意の対象 1（枝問2も可）／語意 1／傍線部解釈 1／内容説明・心情・理由 1／和歌がらみの空欄補充（選択肢が和歌または和歌中の語句）1／内容合致 1（3回に1回は「合致しないもの」） |
| 選択肢 | 5択（イ〜ホ）。正答と紛らわしい選択肢を1つ入れる。 |
| 記述 | なし |

### 4-2. 商学部型（大問(二)想定・目安15〜20分・マーク＋短い記述1）

| 項目 | 仕様 |
|---|---|
| 本文 | 1,200〜1,500字（標準は1,400字前後） |
| 題材 | 中世の説話、または近世の読本・随筆（主語の省略が多い会話のある文章）。和歌は2回に1回の割合で1〜2首入れ、修辞の設問を付ける。 |
| 設問数 | 6〜7問（解答数8〜10） |
| 型の配分 | 脱文挿入 1（挿入位置の直後の3〜5字を書かせる記述）／文法 1／語釈 1／空欄補充 1（枝問3〜5、語群から選ぶ）／傍線部解釈 1／内容合致 1／オプション: 和歌の修辞 1、または古典常識の事項記述 1 |
| 選択肢 | 5択（イ〜ホ）。空欄補充の語群は枝問の数より多くする（例: 枝問5つに選択肢8つ）。 |
| 記述 | 1題（抜き出し・脱文挿入の位置・古典常識の語のいずれか。字数は3〜10字） |

### 4-3. 共通の注意
- 出典は「知名度の低い中世〜近世の作品」を基本にする。有名作品を使うときは、堺本『枕草子』のように教科書と違う本文や箇所を選ぶ。
- 難易度は2段階を用意する。標準は2026年度並み（やや易）、発展は2025年度並み（和歌あり・合致問題がやや難）。
- 解答解説には、主語の補い方、敬意の方向、和歌の修辞を必ず書く。
